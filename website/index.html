Features

Everything you need to study smarter

Pomodoro Timer

Focus, short break, and long break modes with a beautiful animated ring and break overlay.

Focus Guard

Automatically snaps the app back to focus if you switch to a non-allowed window mid-session.

Calendar

Month, week, and list views with meeting links and 5-minute native notifications.

Meeting Records

Screen recording built in. Notes sync directly to Apple Notes with one click.

Rewards System

Earn points for studying. Set wishlist goals and the app assigns point values automatically.
