## Features

- **Calendar** — Month, Week, and List views with meeting links and 5-minute notifications
- **Study Mode** — Pomodoro timer with Focus Guard (auto-refocuses the app if you switch to a non-allowed window)
- **Meeting Records** — Screen recording with notes synced to Apple Notes
- **Rewards** — Earn points for study sessions, set wishlist goals, and unlock rewards

## Running from source

```bash
npm install
npm start
```
